# ⚽ TipsFoot - Plateforme d'Analyses et Grilles Loto Foot

Bienvenue sur le dépôt officiel de documentation et de ressources pour **TipsFoot**, la plateforme de référence dédiée aux pronostics de football, aux grilles **Loto Foot** (7, 8, 12, 15) et aux tendances **Parions Sport / FDJ**.

## 🚀 À propos de la plateforme
**TipsFoot** (accessible sur [https://tipsfoot.com/](https://tipsfoot.com/)) a été conçu pour aider les passionnés de football et les parieurs à analyser leurs matchs grâce à des statistiques avancées, des comparatifs de cotes et des données en temps réel.

## 🛠️ Stack Technique & Architecture
Ce projet s'appuie sur une architecture web moderne et performante :
*   **Frontend :** Nuxt 3 / Vue 3, SCSS responsive design.
*   **Backend & API :** Node.js, Nitro proxy event handlers, Redis caching.
*   **Optimisation :** Cloudflare Workers, compression zlib, gestion multilingue et routage optimisé.
